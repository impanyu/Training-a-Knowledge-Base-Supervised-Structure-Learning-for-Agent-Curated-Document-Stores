# What was actually submitted

Frozen copies of the artifacts sent to the venues, so that later edits to
`paper/main.tex` never make it unclear what the reviewers saw.

| file | what it is |
|---|---|
| `paper.pdf` | the 10-page PDF submitted to IEEE BigData 2026 (paper ID `BigD1187`) |
| `arxiv-source.tar.gz` | the LaTeX source package uploaded to arXiv: `main.tex` plus the three figure PDFs |
| `abstract.txt` | the abstract as plain text, as pasted into both submission forms |
| `title.txt`, `keywords.txt` | the same, for the metadata fields |

`submit/arxiv/` is the unpacked form of the tarball and is gitignored.
